---
title: Website and app problems while booking
route: booking
---
If the website or app shows an error while booking, the customer should check their email before trying again: the booking may have gone through.

If they were charged but got no confirmation, agents can find the booking with the name and the last four digits of the card used, sent by direct message.

If a fare disappeared because of a site error we can confirm, agents can honor the fare that was shown when the error happened.

Reward travel is booked the same way. Blackout dates don't apply to reward seats, but the number of seats per flight is limited.
