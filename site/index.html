Jetway: which team should answer this tweet?

A triage service for an airline’s social media desk. It routes each message to a queue, hands uncertain ones to a person, and drafts a reply that can only say what the policy says. Trained and tested on 14,000 real customer tweets.

What went into it

  • A label leak, found and fixed. Before release, someone replaced “cancel” and “late” with the label names inside the tweets (“Cancelled Flightled”, “Late Flightr”), in about 1,470 of them. The cleaning step reverses it.
  • A time-based split. Random splits hide shifts like Feb 22’s disruption spike. Production models always predict on newer data than they trained on.
  • Brands hidden. Airline handles become “@airline”, so the model learns complaints, not which airline had a bad week.
  • Grounded drafts. Replies may cite only retrieved passages, and every dollar amount, mile count or time limit must appear in them. A person approves every reply before it posts.
  • A small serving image. The champion is scikit-learn, so the Docker image has no TensorFlow. CI builds it and sends it real requests on every push.
